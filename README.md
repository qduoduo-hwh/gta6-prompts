## How to use

1. Choose a prompt below and copy its complete text block.
2. For photo-based prompts, upload your reference photo to an image-capable model, then paste the prompt. Scene prompts can be used without a photo.
3. Customize the subject, clothing, props, lighting, or aspect ratio. For template swaps, follow the image order shown with the prompt.

Prompts are in English. Results depend on the image model and its support for reference images.
